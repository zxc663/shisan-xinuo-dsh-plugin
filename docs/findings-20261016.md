## 4. 治理-token 平衡：四原则与砍除清单（阶段三落地）

**四原则**（写入项目规则文件作常设决策）：
1. **谁消费谁付钱**：人→UI 卡片；模型→最小锚定文本；审计→落盘不进上下文。
2. **边际收益递减即砍**：第 N 次重复相同状态行=0 收益。
3. **prefix cache 是最大隐性税**：一次系统段原地替换=全历史重算——稳定性优先于信息新鲜度，新鲜状态走按需工具。
4. **量化先行再砍**：迁移类改动先跑对照实验；砍除类（纯零收益）立即执行。

**砍除清单**（零收益已可判，立即可执行）：
- 状态行逐轮重复的静态字段（动态字段除外）
- 计分板（GATE 齐 N/缺 N）出模型可见面 → 卡片/日志（B4）
- 只记录不拦的字段出状态行（A10：v/level 自报）
- 启动类遥测同值 13 条去重（rules/budget/discipline/arm 各 13）
- L1 任务用 3 字段简式 GATE（level/v/exit）
- 文本 GATE 维持禁用（F-01）
