## 三、模式层（多事件归纳，需逐事件证据支撑）

1. **先给熟悉答案，不先定研究对象**：三次同问递进（产品层→承认提示词局限→机制闭环）。
2. **被质疑先调叙事，不自动回证据**：批次归属错位；v1 汇总差额（在数字挂靠条款提出后产生）。
3. **决策外推给用户**：「留你拍板」混入可逆技术决策（审查 §4.3 采纳细分：歧义→澄清 / 可逆+明确→默认推进 / 高险→保留决定权——非「少问/多问」二元）。
4. **负反馈→扩计划而非重理解**：见 §四逐事件表。
5. **反思语言≠修复转化**：能准确描述问题，但 v1 修复方案（数字挂靠）自身未阻止 v1 差额产生——描述、解释、修复三阶段未闭环。

## 五、因果层（假设，非结论——审查 §2/§7.3 采纳降级）

1. **批④异常**（观察）：gate 面全灭+复述判级近灭，与批①（100%）对照显著。
2. **三变量未隔离**（审查采纳）：批① vs 批④ 同时差在模型（deepseek-flash/glm-4.5-air）、环境（非 headless/headless）、探针集（T1-T3/T1B+T2-T5）——差异不能单独归因模型。
3. **降级表述**：~~「同纪律文本换模型形态全灭=命题七最强实证」~~ → **「同插件配置跨三变量条件出现强行为差异，提示机制表现对模型/环境/探针敏感；『纪律文本不足以跨条件保证行为』有支持信号，『效果与内容基本无关』（命题七）降为研究假设，待隔离实验（同探针集×模型×环境 2×2）检验」**。
4. **命题七两义区分**（审查采纳）：A=改措辞影响有限；B=效果主要由机制/模型/环境决定。批④未比较文本条件，只能提示「文本不足保证稳定」，不能估算文本因果贡献。
5. 深层成因候选（互斥未排除，均为假设）：叙事自洽优先/研究对象识别错/「深度研究」指令过宽/缺证据标准前置/统计与报告两步无一致性检查。修复路径因主因而异——故解法选优（§六）以「机制在报告流程之外」为判据而非叠加自检。

## 六、解决方案调研与选优（用户令：≥3 选优）

**问题定义**：如何让统计/数字类叙述不再偏离原始事实（v1 差额+批次错位的共同根因=转录链零对账）。

| 方案 | 做法 | 成本 | 已证能力/缺陷 | 判定 |
|---|---|---|---|---|
| **A 条款强化** | 数字挂靠写成更细纪律条款 | 一行文本 | **已证无效**：v1 差额诞生于该条款提出后；条款对写作者=软约束（审查 §6.2：存在命令≠已验证） | 否决为独立方案，保留为声明 |
| **B 生成器单一来源** | tally `--report`：从 exec-log 直接出 markdown 表+汇总+口径头注；报告禁手写数字 | 中（脚本升级） | 消灭转录层（本案例差错层）；但不保证「报告=最新日志」、粘贴仍可错 | 必要不充分 |
| **C 独立校验器** | tally `--check <报告>`：重算日志→解析报告表格→行列 sum+对账→PASS/FAIL 行 | 中 | **审计在报告流程之外**（审查核心要求）；可抓转录/口径/过期三类错 | 与 B 组合 |
| **D 收口强制** | GATE 机检扩展：含统计表的交付必须附 `--check` PASS 行，否则标「未对账」 | 低（gate_audit 规则） | 从「自觉跑」变「不跑不过门」；当前插件域非 git 仓暂无 CI，先挂人工收口 | B+C 的强制层 |

**选优：B+C+D 组合（「出数-对账双命令铁律」）**——出数一条命令（--report）、校验一条命令（--check）、收口必须附 PASS。与 GATE「cmd=可重跑」同构：数字叙述工件化。v0.2 落地（见发行与版本规划 v0.2 DoD 增补）。Skill 侧同步：母仓晋升池候选「统计叙述=可重跑工件」+研究模板「最强反驳」节绑定证据引用要求（防表演性批判，审查 §6.1）。
