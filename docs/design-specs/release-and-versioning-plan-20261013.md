## 一、定位（一句话）

**基于 DSH 的插件——赋予用户对 DSH agent 更深一层的控制机制**：安装即可配置 agent 行为面（拦截/审计/路由/收口验证），源码白盒，大家可改 DSH、也可改本插件。不是规则堆，是真正生效的规则工作流（行为面可测、流程可复刻修改适配）。

**定位假设 v2（2026-10-13 第四轮外审，待 E1 三臂实验验证）**：「为 DSH Agent 提供一层风险自适应的运行时流程控制：按任务状态和风险决定哪些操作可以执行、哪些流程条件必须满足、什么真实证据足以允许任务进入下一阶段或正常结束。」——重点从「告诉模型怎么做」转向「规定执行过程中哪些行动与状态转换被允许」（运行时控制模型=roadmap §七）。

## 三、S1/S2/S3 介入层级（原「三层下沉铁则」改名消歧；用户已批采纳〔决策〕）

**术语裁决**：L1/L2/L3 在本体系=任务判级（L1 可逆小改/L2 功能/L3 危险操作域六项，代码 L3_PATTERNS/exec-log heritage）——**保留不动**；源码介入层级改称 **S1/S2/S3**。

**双维分离（外审 §三采纳）**：介入深度与运行风险是两个维度——

| 层 | 介入深度（技术面） | 运行风险（独立维度，不随层级自动升降） |
|---|---|---|
| **S1 插件 API** | 只用公开扩展面（register/section/pre-execute/restrict/guard）——**默认层：S1 能做的不下沉** | ≠零风险：插件可注册任意命令执行类工具、访问宿主资源；须按实际权限做独立安全验证（SAFETY：未审计+沙箱不保证隔离） |
| **S2 patch 层** | cordis.patch.yml 组合覆盖（现开发态；发行=正规化 dsh.bundle） | 不改源码但**改变实际加载与行为**；overlay 整行替换语义（§二）→须完整性校验 |
| **S3 fork/改 DSH 源码** | 直接改宿主 | **默认不下沉**；必须时四铁则：①补丁 diff 分发可审可拒②升级回归防线（三机检+五套单测+行为探针）③版本锁定+升级 SOP④上游 PR 优先 |

三场景（「插件被砸了怎么改」〔决策〕）：定制=Config 面+content fork（S1）/迭代=兼容范围测试策略（§五 v1.0 前置）/上限=按 S3 四铁则。

deferLoading≠全路由可用按需加载：官方区分各 transport 对工具更新/延迟加载支持差异；外审引 2026-10-08 社区报告（特定 DeepSeek Messages API 配置下延迟工具从可见列表消失且无激活通道——**线索未独立核实，列 v0.4 第一前置项**）。v0.4 第一步=目标模型×路由×宿主环境实测工具的隐藏/发现/激活/调用四环，不通则改整表装配+运行中 restrict 收窄的替代方案。

### v0.5 有效性判定矩阵〔本版核心交付=规则本身，实验前冻结〕

**指标分层**：过程指标（gate-tool 调用率/真实验证完成率/误拦率/漏检率）判「机制是否按设计运行」；**主要结果指标（预注册指定，判定以它为准）**：任务完成率+关键错误率+返工量+耗时；调用率上升不构成有效性证据（可能=过度检查）。

**五结果五决策（预注册 v3 冻结，不得见结果后临时定标）**：
1. 主要结果指标改善且过程指标正常 → 支持发行（进 v1.0 前置）
2. 无显著差异且**实验区分力不足**（样本/功效不够）→ 补样本或重设计，不判无效
3. 无差异且区分力充分 → 判「未证有效」，如实报；发行=仅「实验性」明确标注或不发行（届时请示）
4. 过程正常但结果劣化（误拦抵消收益等）→ 返工，不发行
5. 机制未按设计运行 → 回 v0.2-v0.3 修机制，实验作废

**预注册 v3 变更透明**：记录旧版问题/修改内容/依据/时间/已观察过的结果/新确认性实验起点——探索与确认分离，改指标不算偷跑（外审 §7.2 采纳）。

**发行四条件**（有效性之外）：安装实测/兼容范围（最低版本+已验证 rc+允许稳定版+明确不支持版+升级必跑测试——peerDeps `\|\|` rc 为**本插件自选策略**〔非通用要求〕）/文档齐/安全边界说明。

## 七、解法选优：确定性分层制度（用户令 ≥3 选优）

**问题**：规划文档把四类确定性不同的内容（已批决策/已证事实/待验假设/对外主张）写成同等确定——本轮外审 P0 全部六项的共同根因。

| 方案 | 做法 | 已证能力/缺陷 | 判定 |
|---|---|---|---|
| A 写作纪律条款 | 人工自觉分层标注 | **已证弱**：v1 混写发生在分层意识在场时（同对话弧批④降级之后仍写「最强实证」级断言） | 否决为独立方案 |
| B 四区结构化 | 文档内强制分区（§决策/§事实/§假设/§主张），区外禁写对应类内容 | 结构上使混写不可能；靠作者守区 | 采纳（本档 v2 即首例） |
| C 主张状态标签+绝对词 lint | 每主张带状态标签；门禁正则扫「绕不过/零风险/全为/最强/必然」等绝对词无标签即红 | 机检可见；抓不了标签错标 | 采纳（lint 随 v0.2 工具面落地候选） |
