# 「DSH自定义」系统提示词管理 · 设计冻结（2026-10-17）

> 性质：设计冻结稿（先设计、后立项施工）。依据＝《DSH自定义·调研报告》（`dsh-custom-prompt-research-20261017.md`）与《配置入口惯例调研》（`config-entry-research-20261017.md`）。
> 状态：**待拍板**——本档按「自研全栈（路线 B）」给出分期骨架；其 P0 对「复用为先（路线 A）」同样成立，可独立交付。拍板项见 §8。

## 1. 定位与不变量（需求口径，已澄清）

1. **页面**：「DSH自定义」；入口＝侧栏「插件」→ 本插件卡片 → 设置页（既有惯例；设置区独立入口列为可选增强）。
2. **两大能力**：①管理/深度自定义**官方系统提示词**；②**纪律文本作 system 层前置**。
3. **载体**＝**插件自管全局文件**（单一真相源，建议 `$DSH_HOME/dsh-custom/`：`discipline.md`、`override.md`、`scope.json`、`backups/`）；**文件＝权威层、页面＝编辑面**。
4. **作用域**：**全局默认＋单工作区可覆盖**（复用“按位置匹配、越具体越优先”的成熟裁定：完全一致/前缀/包含/正则；空正文=在该位置关闭）。
5. **注入总开关**：面向分发场景——用户可一键**完全关闭**本插件的任何注入（关=模型只看到纯宿主提示词）；深改另有独立开关。
6. **不按单 agent 场景硬编码**：作用域与开关皆为配置面一等公民；注册按目标作用域进行（会话/agent 作用域覆盖机制在装配链中已有一手证据）。
7. **升级不碎为主**：全部走**合法注册机制**（外部段 order、complete、公开 `assemble()`）；不触碰 asar；0.2.1 线兼容设计（**不得依赖 `{{cwd}}` 变量**）。

## 2. 机制选型（冻结，证据见调研报告 §1）

| 能力 | 机制 | 键位/要点 |
|---|---|---|
| 纪律前置（system 层） | 外部段注册，order＝**−2000**（先于官方 −1000 身份行） | 文本来自 `discipline.md`；`interpolate:false` 原样保留（防变量误插值） |
| 深度自定义官方全文 | **`complete:true` 段**（整段替换；工具/上下文仍照常） | 独占：同 scope 多于一个 complete=组装失败 ⇒ 启用前须做冲突检测 |
| 实际装配视图（页面①区） | **公开 `assemble()`**＋导出 `renderPrompt()` | 段列表（名/顺序/文本）＋**归属标注**：官方（已知顺序常量与段名）／本插件／其它外部 |
| 工作区覆盖 | 会话/agent 作用域注册（同名遮蔽全局） | 页面选择作用域→该作用域注册覆盖段 |
| 热生效 | 每次组装按文件时间戳重读 | 改完下一条消息生效，无需重启 |
| 回滚 | ①关开关即恢复官方（零持久改动）②保存前版本化快照 `backups/<时间戳>/` | 存储损坏检测＋首存前自动 `.bak` |

## 3. 页面三区（冻结）

1. **区一·官方提示词（只读）**：实际装配结果（当前模式/工作区），渲染视图＋源码视图；每段带**归属徽标**（官方／本插件／其它外部）与顺序值；顶部标注模式来源（标准/完全权限等影响装配的档位）。数据＝`assemble()` 即时取。
2. **区二·深度自定义**：`complete` 模式——「接管官方提示词」开关＋Markdown 编辑器（**种子文本＝当前官方装配快照**，一键“取材于当前”）；保存管线＝**干跑校验**（`renderPrompt` 对候选文本＋当前变量表；未知 `{{变量}}` 一律阻止保存）→ 版本化快照 → 落盘 → 生效；提供**全部历史版本**列表与一键回滚；启用时横幅提示**complete 独占**（检测到其它 complete/近邻插件的“身份替换”形态时明确互斥提示）。
3. **区三·纪律前置**：纪律文本编辑器（Markdown）＋增量预览（模型将看到的前 N 行）＋**注入开关**（本区总开关）＋**作用域清单**（全局默认一行；可加工作区规则行：路径＋匹配方式＋文本或“关”）；**AGENTS.md 共存检查**：检测 `$DSH_HOME/AGENTS.md` 与会话工作区链上的 `AGENTS.md`；若其内容与本插件纪律同源/重复 ⇒ 横幅提示（**只提示、不动用户文件**）。

## 4. 安全与护栏（照抄成熟先例）

- **禁模型改写存储**：注册 `tools.guard` 拒绝一切指向 `$DSH_HOME/dsh-custom/` 的写操作（文件工具与含写入特征的 shell），只读命令放行（近邻同款先例）。
- **保存即快照**：任何写入前落到 `backups/`；坏存储不静默——页面说明原因且免覆盖（首存前先备份）。
- **变更留痕**：快照含时间戳与操作来源；“关闭注入/恢复官方”一键可达。
- **导出/导入**：JSON（含纪律、覆盖、作用域），便于迁移与审计。

## 5. 分期与验收

| 期 | 内容 | 验收判据 |
|---|---|---|
| **P0** | 存储骨架（目录/快照/守卫）＋**区一只读视图**（实际装配＋归属标注＋双视图） | 视图与宿主 `assemble()` 实取一致（抽查≥3 会话/2 档位）；改写存储被 guard 拒绝（负向控制）；无 dict 变更时零行为差异 |
| **P1** | **区三纪律前置**（文本/开关/作用域/AGENTS 共存检查）＋热生效 | 开=模型可见前置纪律（会话基线取证）；关=纯净（对照取证）；工作区覆盖生效与转移正确；AGENTS 重复检测触发 |
| **P2** | **区二 complete 深改**（编辑/干跑校验/快照/回滚/互斥检测） | 启用后模型所见=编辑文本（源码视图取证）；`{{未知变量}}` 被阻止（负向控制）；回滚后恢复官方逐字一致；与近邻同挂的互斥提示出现 |
| **P3** | 导出/导入、AI 调校（可选）、设置区入口（可选）、英文文案 | 按各项自证 |

**Non-goals**：不做请求改写/输入框草稿类功能（生态已有且属另一层）；不做会话日志改写（证据底座红线）；不做提示词内容的“云同步”；不改判定/执法语义（那是 core 的面）。

## 6. 风险与回滚

| 风险 | 处置 |
|---|---|
| complete 与生态/未来机制互斥 | 启用前全量检测＋横幅互斥提示；默认**不开** |
| 严格插值炸组装 | 保存前干跑校验（未知变量阻止保存）；文本默认 `interpolate:false` 交给我们控制的段 |
| 与 `dsh-agent-persona` 同挂冲突 | 文档与页面双重提示：其“身份句替换”与本插件 complete 二选一；P0 起即做检测 |
| 0.2.1 升级（`{{cwd}}` 移除等） | 设计不依赖该变量；升级走独立事项（三档矩阵重验） |
| 载体文件被外部编辑 | 时间戳重读＋格式损坏保护（近邻同款）；版本化快照兜底 |

## 7. 与既有资产的关系

- **复用面**：作用域匹配/热生效/备份/守卫/查看视图的机制与 UX＝近邻已成熟（Apache-2.0）；若拍板走**路线 A**，本设计收敛为“complete 深改＋AGENTS 共存＋段归属”三个净增量小件。
- **与 core（执法层）**：完全独立，互不依赖；本插件可单独装卸。
- **入口惯例**：客户端半打包（`__ModuleLoader__`＋externals-only）、表单五惯例、写回经 config-editor 或自管文件（本件取自管文件，因文本体量大）。
