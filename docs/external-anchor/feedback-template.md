# 反馈模板

> 提交 Issue／Discussion 时按此填写，能让问题**可复算**。仓库既有 Issue 表单（`.github/ISSUE_TEMPLATE/`）为结构化入口，本模板给「字段之外要写什么」。

## 必填

- **你做了什么**：完整命令 / 完整操作序列（可复制）。
- **你期望什么**：一句话。
- **实际发生什么**：原文输出（不要转述）；有截图更好。
- **怎么复现**：从干净环境到出事的最短步骤；能否稳定复现（n/n 次）。

## 环境

- 宿主版本（DSH）与绑定线；本插件版本（commit 或 tag）。
- 档位/模式（标准／完全权限）；模型档位（**不要贴密钥**）。
- 操作系统与 Node 版本。

## 证据（有则附）

- `exec-log.jsonl` 中相关行（`kind` 与字段即可；**请先确认不含密钥**）。
- 会话日志中的 `approval/asked→decided` 行（如涉审批）。

## 边界声明

- 本插件**不是安全边界**；反馈「疑似绕过」时请附**对照**（关掉插件时是否同样发生）。
- 未复现的观察请标「未复现」，不要写成结论。
