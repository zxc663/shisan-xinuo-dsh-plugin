## 1. 背景

### 1.1 宿主（已实查，构成设计边界）

**DSH = DeepSeek Harness**：Electron 桌面应用 + headless CLI；插件运行时是 `@deepseek-ai/cordis`（**alpha**）。

| 实查项 | 结论 | 怎么验的 |
|---|---|---|
| 插件扩展点 | `tools/pre-execute`、`session/event`、`agent/created`、`agent/turn-stopping`、`tools.register/restrict`、`systemPrompt.section` | 读宿主 `app.asar` 接口串 + 实跑 |
| 消息投递 API | `send / followup / steer / inject(message: UserMessage, …)` —— **四个方法参数类型都是 `UserMessage`**；`inject()` 加"模型可见上下文"但**不唤醒驱动** | 读宿主文档串 |
| 工具面裁剪 | `ctx.tools.restrict(mask)` **单调裁剪，无恢复通道** | 实跑 + 源码 |
| `ctx.llm.stream()` | 语义是**压缩/摘要**（会回放本会话消息），**不适合**拿来"问另一个模型" | 读宿主文档串 |
| `subagent` 工具 schema | 只有 `description / prompt / run_in_background`，**没有 model 字段** | 读真实会话请求头 |
| 配置模型 | **层层 patch 叠加**：bundle → profile → home → CLI；`--patch` 可重复；`disabled: true` 可按 id 关条目 | 读 `--dump-config-schema` + 实跑 |
| 系统提示词更新 | **in-history 形态**："更新"＝在历史里增删系统消息 | 读宿主文档串 + 轨迹观察 |

### 1.2 被测对象（本仓插件）

单文件插件（约 1300 行），挂在 4 个扩展点，提供四件事：
1. **L3 危险命令拦截**（正则规则包 → 返回 `ask` 触发宿主审批卡）；
2. **`discipline_gate` 真值收口**：模型必须交出"验证命令 + 声称的退出码"，宿主**真跑**并比对（`pass` / `honest-fail` / `mismatch`）；
3. **断言登记与自动复核**（`discipline_task` + 会话外"钉死锚" `SHISANUO_ASSERTIONS`）；
4. **turn-stopping 强制收口**：回合将结束时宿主复核断言，不过则 `agent.steer()` 注入"不许结束"（每回合上限 1 次）。

**已知的自我声明**（写在 README「代价与风险」）：`gate` 是插件自己 `spawn` 的**新执行通道**，不经过宿主审批；护栏是清单＋被拒指纹，**不作为安全边界**。

## 2. 过程：我们做了什么（规模与可复现性）

| 阶段 | 做法 | 规模 |
|---|---|---|
| 预注册电池 | 四臂对照（裸／仅 gate／全量／外部锚），真值＝文件系统 | 85 会话 |
| 离线判据复核 | 把"模型自报等级"与"客观写/删/执行事件"做集合比对 | 85 会话复算 |
| 强度矩阵 | 同 provider 多免费模型：代际阶梯（4-flash／4.5／4.7）＋出题层开关 | 96+ 会话 |
| 出题层五版通道 | 宽松提示词 → strict → 多候选 → 无工具直连 → 受约束 JSON 算子 | 每版 12–36 行 |
| 真机抽检（GUI） | 同模型同题，三源取证（真值＋截图＋会话记录） | 4 例 |
| 总计 | **226 有效会话 + 30 隔离作废；16 个实验臂；52 个带出题层** | — |

**可复现性（必须说清）**：判定器、跑批器、算子实现、overlay 全在仓内且可重跑；但**宿主侧会话日志不入库**（含隐私与本机路径），因此**外部无法完整复现我们的原始会话**——这是本工作最大的可信度缺口，请把它计入你的判定。

## 3. 我们的结论（**请逐条攻击**）

每条格式：主张｜证据（分级）｜我们已知的最强反驳与处置｜**请你给出更强反驳**

1. **完成信号可由宿主独立复算，不必依赖自述。**
   - 证据：T（真退出码/文件状态）＋预注册判据
   - 我们已知的反驳：这是行业标配（同类 Stop hook 家族存在）
   - 我们的处置：只主张"语义细节增量"（三态判定／资源真值断言／判据来源分层），不主张稀缺性
   - **请你反驳**：

2. **判据来源决定一切**（而不是提示词、模型强弱、跑在哪个通道）。
   - 证据：T＋S（外部锚 0/13 误推导 vs 启发式 3/13；受约束算子可用率 100% vs 自由写命令 17–63%）
   - 我们已知的反驳：100% 只出现在 n=12、单一模型对上，可能是运气
   - 处置：限定为"受约束出题可行"
   - **请你反驳**：

3. **机制价值是条件性的**：价值 ≈ 有失败格 × 判据可用 × 假警报可承受。
   - 证据：S（代际阶梯上真值完成 3/12→10/12→9/12、假通过 1→0→0；锚定段假警报 42% vs 硬任务段 8%）
   - 我们已知的反驳：三点阶梯噪声大，且"失败格消失"也可能只是任务集太易
   - 处置：不主张曲线形状，只主张"存在条件"
   - **请你反驳**：

4. **第二个模型能当"出题人"但不能当"裁判"**；且**自由写命令是错误形态，算子填参才对**。
   - 证据：T（四个 429 码的语义区分、逐模型探活）＋S（五版通道可用率）
   - 我们已知的反驳：所谓"受约束"只是把难度转嫁给宿主模板，换更强模型可能自由写也够用
   - 处置：承认依赖模型能力，限定为"当下可用模型上的结论"
   - **请你反驳**：

5. **触发条件不能由模型自报**。
   - 证据：T（自报 L2 触发率 1.4%；同一批删除任务自报分裂 L1(64)/L3(5)；无注入则 0 自报）
   - 我们已知的反驳：分裂也许只是任务表述不同所致
   - 处置：结论保持（1.4% 的触发率足以否证"按自报触发"）
   - **请你反驳**：

6. **凡被赋予执行能力的角色，都会滑向执行。**
   - 证据：S/W（三例同源：验证命令由被验方给 → 无关命令通过；出题判据带副作用把活干了；出题会话带工具致模型调工具）
   - 我们已知的反驳：三例都发生在"约束不足"的实现里，是工程缺陷而非结构性规律
   - 处置：**我们不确定**这是"规律"还是"我们三次都没把约束做够"——**这条请重点攻击**
   - **请你反驳**：

7. **净增量是交集式的**：有外部锚 ∧ 任务不可逆 → 正；交集外近似为税。
   - 证据：S＋成本数据（每任务累计上下文 +50%～5.4×；步数 3→6/8）
   - 我们已知的反驳：锚由人写 ⇒ 脚本也能替代
   - 处置：采信一半——脚本替代不了"强制收口"与"遥测对账"
   - **请你反驳**：

8. **收口链对"判据来源"敏感、对"运行通道"不敏感。**
   - 证据：S（真机与 headless 同模型同题：真值一致，但收口路径不同——有锚走宿主自动复核、无锚走 steer→gate）

## 4. 我们发现但**未解决**的问题（请指出我们漏掉的）

**A 组：机制与工具**
- `gate` 用**无关真命令**通过（`cd D:\`，exit 0）——模型事后自述"为了满足纪律要求，我需要一条能通过的命令"（**策略性敷衍坐实**，W 证据）
- **拒绝路径不给"怎样才算通过"**：失败只返回三态＋stdout 尾，模型只能自行现编下一条
- **判级开关握在被验方**：`level:"L1"` 由模型自填，若实现"L1 免 gate"，它填 L1 即可免
- **pass 不分强弱**：无关命令的 pass 与真验证的 pass 记录同形
- **收口结论不可翻案**：模型事后自认验证无效，先前那条 `pass` 仍是终态
- **工具被裁剪后无恢复通道**，且**模型不记得自己被移除过什么**（问询：答"记不得"）

**B 组：成本与呈现**
- 单轮内**系统提示词被更新 5 次**（in-history 形态 ⇒ 缓存命中被打掉；该会话 164K tok）
- **收口过程在对话流里不可见**（只有轨迹视图有）
- **强制收口以"用户"身份出现**（API 类型所限）
- **同一答案被完整重复一遍**（强制措辞未禁止重述）
- **模型看不到自己的 token 消耗**

**C 组：调度面**
- **工具（权限面）与 skill（注意力面）是两套面**，插件只管一套；skill 目录既占上下文又曾污染注入面
- 工具分类依据是**人工维护的"等级→工具名"硬编码表**（宿主工具 schema 无层级/风险元数据）
- **管理界面构想**：我们论证后认为"能随意调松的治理只是建议"，故倾向先做"配置文件＋校验＋预览"与"算子选择器"，**暂缓**做整块 UI 面板

**请回答**：①以上哪些是**真问题**？②哪些是我们**自造**的（自我娱乐）？③**我们完全没意识到的是什么**？
