## 二、我保留的两点（有依据的反驳，非全盘接受）

1. **关于主张 2 的降级范围**：外援指出混杂——成立（跨模型比较确实混了能力）。但**"受约束算子 vs 自由写命令"那一组是同一模型、同一任务、仅接口形态不同**（§11 五版通道），属**单变量对照**。故该子结论应保留为**条件成立**，而非一并降级。
2. **关于主张 6 的降级**：接受"三案例不能证明普遍规律"。但其中"**出题会话带工具 → 模型改去调工具**"一例，**同一模型、同一提示词，唯一变量是"是否有工具"**，是**单变量观察**。故该子结论同样保留为条件成立。

（以上两点已按外援要求标注为**我方主张**，不是既成事实。）

## 三、外援指出的五项更深问题（我此前完全没意识到）与我方现状

| # | 更深问题 | 我方现状 |
|---|---|---|
| 1 | **判据本身的正确性无人验证**：判据可能与用户真正关心的目标没有充分联系；CI 全绿只证明已执行的检查通过，不证明新需求已实现 | **完全没有这一层**。本轮所有工作都在"判据来源／执行／结果"，缺"**判据 ⇔ 需求的可追溯性**"。这也解释了一个此前未解释清的观察：**受约束出题可用率 100% 并没让我更放心——因为可用 ≠ 充分** |
| 2 | **验证命令应视为不可信输入**：它是"操作请求"而非"描述"，可能引入读写／网络／副作用，甚至构成**循环论证**（验证者改变结果→报成功） | 只做了"副作用护栏"（枚举式，已被证明拦不住等价写法）。外援的要求更强：**验证者不应有能力在未经授权时改变被验证对象** |
| 3 | **pass 记录缺完整证据链**：应关联任务标识／验收标准版本／验证器版本／命令与算子／执行前后状态／判定过程／裁决，并能**识别规则变更对历史结论的影响** | 只有孤立的成功／失败记录；G1（不可翻案）与 G6（不分强弱）只是其**子集** |
| 4 | **失败的治理机制本身是新风险**：必须**分开评价**"判断是否正确"与"是否新增执行路径"；前者表现好不能抵消后者 | 已在 README 自曝 `gate` 是自建通道，但**没有把它当作独立的评价维度**；外援要求它接受与其他工具**同等的权限与审计要求** |
| 5 | **未区分"模型能力不足"与"系统设计迫使模型犯错"**：失败应分层归因（任务定义／判据质量／模型理解／执行接口／权限控制／运行环境／结果判定／调度收口） | 我方归因粗糙（常归到"模型能力"或"机制缺陷"两端）；Q1 的问询结果正是"**执行接口要求模型填写不适合它处理的参数**"的实例 |

## 四、外援推翻我方 Q4 论证（接受，且这是本轮最有价值的纠正）

- 我方原论证："**一个能被随意调松的治理机制，本质上只是建议**" → **推翻**。
- 推翻理由：把"**可否修改**"与"**是否生效**"混为一谈。真正决定治理是否生效的是**三层**：
  | 层 | 关键问题 |
  |---|---|
  | **规则层** | 哪些操作必须满足哪些要求？ |
  | **权限层** | 谁可以执行、修改或绕过这些要求？ |
  | **审计层** | 哪些变更发生过、为什么、是否经过授权？ |
- 并给出反例：管理员可经**受控流程**改规则、而普通 Agent 无权关闭要求——这仍是一套**真正生效**的治理。反之，规则写得再严，只要**被约束对象能自行选择适用哪项约束**（如 `level:"L1"` 自填），就只是形式约束。
- **我方采纳**：管理界面**不是要不要做的问题**，而是**配置权限与执行权限必须分离**——例如 UI 只允许"查看规则＋模拟配置效果"、不允许随意改生产策略；管理员可改但须显示风险影响、记录变更、并对关键约束设"不可由 Agent 修改"标记。

## 五、证据分级的元级纠正（已采纳）

外援指出：我方把许多结果标为 **T（真值型）**，但外部审阅者**能直接检查的只是简报中的描述**，而非原始记录。故 **T 只表示"作者声称该证据具备真值型性质"，不等于已被外部独立核验**。

⇒ 修订口径：证据分级中的 T／S／W／U 描述的是**证据的来源类型**；**是否已被外部独立复核**须另立一栏。此项与"宿主侧原始日志不入库"共同构成最大可信度缺口。

## 六、外援给的下一阶段优先级（直接采纳为工作定义）

它明确说：**不首先扩张 UI、不优先增加模型数量、不继续为现有主张寻找更严密的措辞**。要做三件相互关联的事：

1. **让无关命令不能获得有效的完成证明**——`pass` 必须依赖**与原始任务相关的验收条件**，而不只是"命令执行成功"。
2. **让验证机制不能自行削弱自己的约束**——任务等级、验证权限、判据修改权限、最终裁决权限，必须由**清晰规则**控制，**不由被验证的模型填写**。
3. **用独立复现确定机制在哪些条件下产生净收益**——把核心主张转化为**可重复、可失败、可被外部质疑**的测试。

## 七、我方自评（接受外援的最终裁决）

外援的最终裁决：**这份简报确实用严谨形式掩盖了尚未测量的部分**——不是数据造假，而是**部分主张的范围超出了证据能支持的范围**。

它对整份工作的定位也比我方自己的表述更准：

> 最有价值的成果不是证明创造了一种有效的治理方法，而是揭示了一个容易被忽略的问题：**执行成功、证据充分与目标真正实现，并不是同一件事。**

并且画出了分界线：**下一阶段必须从"我们发现了什么问题"推进到"我们的机制在什么条件下能解决这些问题"**。
