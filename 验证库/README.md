# 验证库（可复跑的证据）

本库回答两个问题：**当前能证明什么**，以及**别人能不能自己重跑一遍**。

## 先读：发行口径

**只有打包好的公开发行版才算真实验证可用。** 本仓当前**无 tag、无 release**（尚未发行），但**已具备打包形态**：`package.json` 自 `1d00ffd`（2026-10-15「发行形态打通」）起声明 `dsh.bundle`，且**干净克隆 pack 与装载已实测通过**（见 [已知边界与接受风险.md](./已知边界与接受风险.md)）。发行本身暂不进行（先经过实际环境验证）。因此：

> **本地工作树（2026-10-16 更新）**：此前那处**未提交**的 `package.json` 改动（删除 `dsh.bundle`）**已丢弃**，工作树与 HEAD 一致 ⇒ 本地与干净克隆的打包行为相同（此前"本地直接 `npm pack` 会产出非 bundle 包"的例外不再成立）。

- 本库现有证据**全部是开发态证据**，不构成「可用版本」；
- 本库只声明「**机制与过程可复现**」，不声明「产品可用」。

**已知边界与接受风险**（对外可读）见 [已知边界与接受风险.md](./已知边界与接受风险.md)——如实列出机制不能保证什么、已接受的风险与未验证清单。

**外部语料**（非自撰、可外部核）见 [外部语料-上游合规向量.md](./外部语料-上游合规向量.md)——上游 `dsh-permission-rules` 的共享合规向量（来源＋哈希＋复跑法）。

## 三层证据

| 层 | 内容 | 谁能重跑 |
|---|---|---|
| ① 代码级（强） | 29 套单测 + 20 条机制级主张检查 | **任何人**：只要 Node ≥ 22.18，不需要宿主、不需要会话数据 |
| ② 报告级（中） | 预注册、A/B 报告、审计处置、账本对账 | 结论与判据可读；宿主内实验日志不入库，外部不可独立复现（如实标注） |
| ③ 真机级（弱） | 宿主内拦截／审批／收口／界面走查 | 需要宿主与模型配额；本库只提供脚本与协议，不提供可复现的宿主环境 |

## 可重跑命令（①层）

```bash
npm test                                  # 29 套单测（含公开文本机检与 docs 索引机检）；exit 0 = 全绿
node scripts/claims-check.mjs             # 20 条机制级主张；exit 0 = 全部成立
node scripts/tally.mjs --report --freeze  # 出数并冻结快照
node scripts/tally.mjs --check            # 对账；exit 1 = 发现违规
```

**负向控制**：`tmp/mutation-check.mjs` 故意改坏判据 ⇒ 检查器转红。这条用来证明绿灯**携带信息**，不是橡皮章。

## 结论口径：三命题分立

**机制存在（✓）≠ 机制有效（待补样本轮）≠ 产品可用（需打包发行版 + 实际验证）**。把前者读成后者，不在本库的声明范围内。
