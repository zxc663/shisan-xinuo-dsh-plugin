# 推进库（在推进的事）

本库收纳**正在推进的工程事项**：设计档、批次计划、待办、路线与定位校准。**没有验收判据的想法留在 `想法库`**，不进本库。

## 入库标准

1. **有验收判据**：完成长什么样可判定（命令／可观察结果／文档产物）。
2. **有回滚基线**：出问题时回到什么状态（提交号／备份路径／替代方案）。
3. **有边界**：明确不做什么，避免范围扩散。
4. **状态如实标注**：规划中／进行中／已完成／已改判／已放弃——改判与放弃要留痕，不静默删除。
