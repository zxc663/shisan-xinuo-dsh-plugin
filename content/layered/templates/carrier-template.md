# 承载文档模板（工作流承载 · 固定格式）

**触发**：L2 及以上任务、项目工作区根目录新建承载文件夹时。**强制级**：M（建承载时复制填写，禁空占位）。
**承载根**：项目根目录新建专用文件夹（建议 `.xinuo/`，名称以项目规则文件为准）。

## 一档制单文件四区骨架（复制为 `<承载根>/agent-log.md` 后填写）

```markdown
# agent-log · <项目名>（本机承载，不入库）

## 一面状态（状态段 · ≤10 行；每任务块收尾刷新）
> 首行 STATE（单行结构化，禁小作文；与上下文冲突→以本档为准并重读真实文件系统）：
> STATE: task_id=<…> | session=<会话短id> | level=<L1/L2-S/L2-F> | clarify=<无/待澄清/已澄清> | approval=<无需/待批准/已批准/已拒绝/豁免> | gates=<N/最新块> | last_err=<—/症状→处置>
- 目标：
- 下一步：
- 约束：
- 回滚基线：
- （多会话并行时：每活跃会话一行锚）

## 教训库（教训区 · 高频置顶一行，其余按类；同坑复现=修订原条目，禁另立近重复）
### T1 高频必读
- 1. 症状：…｜对策：…
### T2 按类教训
#### 教训 #N [域:通用|平台=<名>|环境] [态:active|fixed|retired] 标题
- 症状：｜根因：｜解决：｜预防：
- 证据：<首记≥1 条，复现时追加>
- 命中: 1（最近 YYYY-MM-DD）

## 偏好段
- （已确认的技术栈/语言/风格；语言默认中文不重复问）

## 流水区（每任务块一行；>200 行或 >150KB 旧行移轮转档——移动非删除）
- YYYY-MM-DD HH:mm | [会话短id] | 改动 | 验证(结果) | 未验证项
- （重要决策另落一行决策审计：决定 | 依据(前提+重开条件) | 被否候选 | 影响）
```

## 承载根目录结构
```
<承载根>（项目根目录，建议 .xinuo/）
├─ agent-log.md          # 一档制四区（本模板正文）
├─ backups/              # 备份分类子目录（备份只允许写在这里，不越过工作区）
│   ├─ <备份文件>
│   └─ backup-info.txt   # 每备份必附：时间(到分)/节点/作用/原因
└─ archive/              # 流水轮转档（>200 行或 >150KB 旧行移入）
```

## 固定格式要点
1. **流水时间戳精确到分**（`YYYY-MM-DD HH:mm`）：真实项目中 agent 迭代速度远快于人工，秒级是噪声；同一分钟内多条追加序号。
2. STATE 单行字段用固定枚举（对齐状态行中文枚举，state 仅 新任务/续接/单次 三值），禁小作文。
3. 教训条目必须有证据行与命中计数；入库前自问「删掉最坏后果是什么／会被怎么误读」。
4. 脚本（轮转/检索/对账）从插件或技能目录复用，不复制进工作区承载——工作区只放数据。
5. **备份纪律**：备份只进 backups/＋附 backup-info.txt；临时备份任务完成后删除，仅 important 备份保留。

## 边界
- 单次/纯只读问答不建承载，交付回复声明「单次：未建承载」。
- 承载根目录名待用户裁定前，默认 `.xinuo/`；项目已有成熟记忆体系时为权威，本档作入口档指针回指、勿双写。
