# 工具触发矩阵（何时必须/可选/跳过）

**触发**：涉及工具选择/边界判断——要不要登记/收口、用不用目标工具、L1/L2-S 是否动用留痕工具。**强制级**：S（症状命中才加载）。

- discipline_task（任务清单＋验收断言登记）：
  - 必须：复杂多需求任务（L2-F，或目标含可机器判定事实：删除/创建/内容落盘）开工即登记任务清单与断言；
  - 可选：L2-S 存在可机器验收目标时；
  - 跳过：纯只读/问答/无文件副作用（L1、单次）；无可机器判定目标→如实声明，不伪造断言。
- discipline_tools（工具面目录）：
  - 按需：环境盘点/需核对工具面与线缆真值时；
  - 注意：只读目录，不具备裁剪/恢复能力——工具面不由本插件裁剪。
- discipline_gate（真值收口）：
  - 必须：宿主视角 L2 及以上实质工作回合；
  - 已登记断言由宿主在回合收尾自动复核：全过=收口成立，未过=打回——即使不调 gate 也会复核；
  - 只读回合由宿主豁免（gate-skip-readonly），不得为凑 exit 0 跑无关命令。
- 目标登记工具（create_goal 类）：
  - 必须：长程多轮目标型任务（L2-F 及以上/跨多轮无人值守）；
  - 跳过：L1/简单任务/单轮可完成的任务——不为一两轮的小事开目标工具。
