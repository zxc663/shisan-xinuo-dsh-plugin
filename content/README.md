# content · 内容资源（提示词体系）

随插件分发的规则与提示词内容，分两层：

- `discipline.md` — **常驻核心**：状态行（中文枚举）／开工协议（确认任务、环境盘点、澄清与提问、判级、证据严谨度 K0–K6、执行与收口）／思考要求与质疑审查（需求四层、三质疑、方案三想一合、调研对比）／承载协议（教训库、一面状态、脚本复用、固定格式，流水精确到分）／红线／收口协议／工具触发矩阵（含目标登记工具）／渐进加载路由。运行时经 `SHISANUO_DISCIPLINE` 或本路径装载，装载失败回退内嵌镜像（两者逐字一致）。
- `layered/` — **渐进加载层**（按需注入的流程细则＋固定模板，用完不驻留）：路由表见 `layered/00-加载清单.md`；强制级 M（触发即必须）与 S（按症状）分开标注；`templates/` 内为承载、规划、验收、任务记录、复盘、回滚点 6 件固定格式模板。宿主按检测结果自动注入对应分节，其余按路由自觉加载。
- `rules.json` — L3 危险域＋只读豁免规则包（装载失败即回退内置默认；契约见 docs/config-contract.md）。
- `agents-md-discipline.md` — `discipline.md` 的**通用兜底版**（复制为项目 AGENTS.md 用），差异三处：无「插件自包含边界」段；承载根为「建议 memory/」而非「固定 memory/」；无「根目录卫生」「文件索引」两条（依赖插件随包脚本）。改任一侧需评估这三处差异是否同步。
- `VERSION` — 纪律内容版本（与 package.json 对齐），跨仓同步对账用；不进模型上下文。

**内容必须可被机制引用或加载，不做"纯陈列"。**
