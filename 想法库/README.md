# 想法库（未验证）

本库只放**随手记下的想法与疑问**——价值在于不丢问题，不在于论证完整。

## 条目规则

- **状态恒为未验证**：未实现、未测试，**不构成任何能力主张或承诺**。
- **保留原始措辞**：一条一行，不在这里替作者改写、不在这里展开论证。
- **命名**：`YYYY年M月D日.md`；同日多条追加在同一文件。
- **升级路径**：想法被接受进入推进时，落到 `推进库`（必须带验收判据与回滚基线）；被验证后落 `验证库`。**本库条目本身不改写成结论**——结论只在 `验证库` 表达。
