# shisan-xinuo-dsh-plugin

> **状态：开发中（developer preview）· 未发行。** 当前仓库仅含脚手架与目录占位，尚无可用代码、无安装包、无 Release。

面向 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的工作流插件：把「十三希诺」工程纪律从提示词层推进到**运行时控制层**——在任务生命周期的关键节点提供可检查、可回退的动作，而不仅是"告诉模型应当遵守什么"。

## 探索方向

- 任务状态与阶段门：状态转换依据可核查的事件与证据，而非模型自述
- 执行前检查：工具调用与操作风险、授权、前置条件挂钩
- 证据与审计：区分"工具执行成功""验证通过""验收达标"
- 内容分层装配：纪律与能力按需注入，控制上下文成本

设计原则：白盒可改、最小必要、按风险分级；机制强度以宿主真实接口能力为上限（不做超出宿主的承诺）。

## 目录结构

| 区域 | 用途 |
|---|---|
| `src/` | 插件运行时源码（控制链本体） |
| `content/` | 内容资源（纪律包、检查清单、模板） |
| `data/` | 运行时数据结构 / schema / 样例（不含真实数据） |
| `docs/` | 设计与开发文档 |

## 版本路线（一句话）

v0.x 最小控制链（任务状态 + 执行门 + 证据记录）→ v0.5 能力路由与纪律分层 → v1.0 公开发行（以对照实验为准，后置）。

## 诚实条款

- 未发行：不提供 npm 包 / Release / 安装说明；接口与数据结构不保证稳定。
- 不预设结论：机制是否有效以对照实验为准，未验证不宣称。
- 边界自知：插件能达到的控制强度取决于宿主提供的接口，文档将标注真实能力边界。
